In MySQL, Update and Delete query wasn’t executing, what was the reason and how to run those query? Write the code to enable the feature

=>
In My SQL if UPDATE or DELETE query aren't executing , common reason is that 'safe update mode is enable'. To run those query we have to disable the safe update mode.
Code id :
    SET SQL_SAFE_UPDATES = 0;
